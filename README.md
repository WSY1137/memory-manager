# Memory Manager · 记忆管理器

> 专业级 AI 记忆管理系统，适用于 TRAE（TraeCode / TraeWork）
> **版本**：v1.0.0

---

## 简介

记忆管理器是一套面向 AI 记忆全生命周期的管理系统，覆盖**采集 → 提炼 → 存储 → 检索 → 维护 → 归档**完整链路。

### 核心特性

- 🎯 **五级记忆体系** — 从会话记忆到跨项目知识库，层层递进
- 🚪 **六级闸门控制** — Trigger / Intent / Quality / Process / Write / Safety，质量与效率平衡
- 🎛️ **配置驱动** — 所有行为可通过配置文件调节，无需改代码
- 🧠 **三级灵活度** — 刚性规则 / 推荐流程 / 可选建议，既规范又不死板
- 🔒 **安全保守** — 写入必确认、删除必二次确认、批量必备份
- 📝 **人类可读** — 全 Markdown 存储，可直接编辑、Git 友好

### 八大功能

| 功能 | 说明 |
|---|---|
| 📦 项目归档 | 项目完成后生成结构化归档，提炼可复用经验 |
| 🔍 知识库检索 | 从全局知识库和历史归档中搜索相关经验 |
| 🧹 记忆整理 | 去重、合并矛盾、优化分类、标记过时 |
| 📝 偏好复盘 | 从近期项目中识别行为模式，提炼稳定偏好 |
| 📊 状态概览 | 记忆统计仪表盘，展示整体状态与健康度 |
| ❓ 帮助信息 | 使用说明、命令速查、常见问题 |
| 🏥 健康检查 | 检查记忆系统完整性与规范性 |
| ⚙️ 配置管理 | 对话中直接调节闸门配置 |

## 安装方法

### 方式一：通过设置导入（推荐）

1. 打开 TRAE → **设置** → **技能与命令** → **技能**
2. 点击 **创建** 按钮，选择 **全局**（或项目级）
3. 上传本压缩包（`memory-manager.zip`）
4. 确认技能信息，点击 **确认**
5. 完成！在对话中说"记忆管家"即可触发

### 方式二：手动安装

1. 将 `skill/` 目录下的 `memory-manager` 文件夹复制到：
   - **全局安装**：`~/.trae-cn/skills/memory-manager/`
   - **项目安装**：`{项目路径}/.trae/skills/memory-manager/`
2. 将 `memory/` 目录下的文件复制到 `~/.trae-cn/memory/`（可选，初始化知识库用）
3. 重启 TRAE 或重新加载技能
4. 完成！

5. **定期复盘**：每隔一段时间说"记忆复盘"，提炼新偏好
6. **偶尔整理**：记忆多了说"整理记忆"，保持健康

## 闸门配置

记忆管理器的行为可以通过 `~/.trae-cn/memory/memory-config.md` 调节。

### 快速预设

| 预设 | 适用场景 | 说明 |
|---|---|---|
| 🔒 严格模式 | 对质量要求高、不怕多确认 | 所有闸门调最严 |
| ⚖️ 标准模式 | 大多数用户 | 质量与效率平衡（默认） |
| ⚡ 宽松模式 | 熟练用户，想减少交互 | 闸门调松，尽量简化 |

切换方式：在对话中说"切换到严格模式"即可。

### 六级闸门

| 编号 | 名称 | 作用 |
|---|---|---|
| G1 | Trigger 触发闸门 | 要不要加载 Skill |
| G2 | Intent 意图闸门 | 真的要做还是随口提 |
| G3 | Quality 质量闸门 | 值不值得做 |
| G4 | Process 流程闸门 | 按多完整的流程走 |
| G5 | Write 写入闸门 | 能不能写入文件 |
| G6 | Safety 安全闸门 | 破坏性操作保护 |

## 安全说明

本 Skill 遵循以下安全原则：

1. **写入必确认** — 任何写入记忆文件的操作都会先展示并确认
2. **删除必二次确认** — 删除记忆需要二次确认，防止误删
3. **批量必备份** — 修改 5 条以上记忆先备份再执行
4. **本地存储** — 所有记忆数据存储在本地，不上传云端
5. **隐私保护** — 不记录密码、密钥、个人隐私等敏感信息
